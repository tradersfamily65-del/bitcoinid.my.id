Privacy Policy
Berlaku sejak: 1 Mei 2026 Versi: 1.0
▸ Ringkasan Singkat
BITCOIN ID tidak mengumpulkan data pribadimu. Tidak ada akun, tidak ada login, tidak ada server kami yang menerima datamu.
Semua data tersimpan hanya di HP-mu sendiri menggunakan LocalStorage browser. Kami tidak bisa membaca data tersebut.
App ini adalah PWA (Progressive Web App) yang berjalan murni di browser — tidak ada backend server yang menyimpan informasimu.
1. Informasi yang Dikumpulkan

BITCOIN ID tidak mengumpulkan informasi pribadi apapun.

Kami tidak meminta, menyimpan, atau memproses:

✓Nama, email, atau nomor telepon
✓Lokasi atau alamat IP
✓Data finansial atau rekening bank
✓Identitas atau dokumen apapun
✓Riwayat browsing atau aktivitas

Data yang kamu masukkan di app (DCA Journal, Price Alert, dll) hanya tersimpan di perangkatmu melalui browser LocalStorage dan tidak pernah dikirim ke server manapun.

2. Data yang Tersimpan di Perangkatmu

App ini menyimpan data berikut secara lokal di HP-mu menggunakan LocalStorage:

bid-journal
Catatan DCA Journal yang kamu input sendiri
bid-alerts
Price alert yang kamu set sendiri
bid-badges
Achievement badge yang sudah kamu unlock

Kamu bisa menghapus semua data ini kapanpun melalui pengaturan browser → Clear Site Data.

3. API Pihak Ketiga

App ini mengambil data dari API publik berikut untuk menampilkan informasi pasar:

CoinGecko API — coingecko.com
Harga Bitcoin, chart, market data. Data publik, tidak memerlukan autentikasi.
Alternative.me — alternative.me
Fear & Greed Index. Data publik.
blockchain.info — blockchain.info
Block height & hash rate. Data blockchain publik.
CryptoPanic — cryptopanic.com
Bitcoin news. Data publik.

Request ke API di atas dilakukan langsung dari browser-mu. Kami tidak menjadi perantara dan tidak menyimpan response-nya.

4. Keamanan Data

Karena kami tidak mengumpulkan data, tidak ada risiko kebocoran data dari sisi kami.

Data lokalmu (Journal, Alert, Badge) dilindungi oleh:

→Keamanan browser/HP-mu sendiri
→Isolasi domain browser (same-origin policy)
→HTTPS encryption untuk semua request API
5. Iklan & Tracking

BITCOIN ID tidak menampilkan iklan dan tidak menggunakan alat tracking apapun seperti:

✓Tidak ada Google Analytics
✓Tidak ada Facebook Pixel
✓Tidak ada cookies tracking
✓Tidak ada fingerprinting
6. Hak Penggunanya

Kamu memiliki kendali penuh atas data lokalmu:

→Hapus data: Bersihkan LocalStorage melalui pengaturan browser
→Uninstall: Hapus app dari home screen kapanpun
→Offline: App bisa digunakan tanpa koneksi (data cached)
7. Perubahan Privacy Policy

Jika ada perubahan pada Privacy Policy ini, akan diumumkan melalui update app dengan tanggal efektif yang jelas. Penggunaan berkelanjutan setelah perubahan dianggap sebagai persetujuan.
